# ToDo App

A simple, lightweight ToDo app that runs directly in the browser.

![ToDo App](images/screenshot.png)

## Features

* Create and manage todo items
* Simple browser-based interface
* JSON-based example todo data
* No backend or database required
* Easy to run locally

## Getting Started

### Requirements

You only need a modern web browser.

If you want to run the included local server script, you'll also need a Windows environment.

### Running Locally

Clone the repository:

```bash
git clone https://github.com/reveriejake/ToDo-App.git
cd ToDo-App
```

You can open `index.html` directly in your browser, or use the included `serve.cmd` script to start the local server.

## Project Structure

```text
ToDo-App/
├── index.html
├── example.todo.json
└── serve.cmd
```

### `index.html`

The main application and user interface.

### `example.todo.json`

Example todo data used by the application.

### `serve.cmd`

Windows command script for running the application locally.
